API base

Every lookup goes to this server. The extension ships no API key and never signs a request — anyone can unzip an extension, so a key inside one is a published key.

Automatic overlay

With this off, nothing is drawn on any page and no address is sent anywhere. The popup still works: you paste an address and only that one is looked up.

Allowed sites

BAZR Tag adds a price tag next to addresses these sites already show. It does not copy what they do, and it reads nothing on a site switched off here.

    Local cache

    Scored mints are kept for 10 minutes, and addresses the API says are not mints for 24 hours, so scrolling a timeline does not spend your rate limit on the same string over and over. Everything lives in this browser profile only.
